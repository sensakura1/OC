# 通世概要

## 纪年规则

当前时间为：

> 通历1000年。

通历是跨国史官、学者和商会使用的公共换算历法，不属于任何国家。

## 各国纪年换算

| 国家 | 纪年起点 | 通历1000年 |
|---|---|---:|
| 天霜 | 961年正式建国 | 建国四十年 |
| 曜穹 | 961年正式建国 | 圣临四十年 |
| 新罗 | 954年宣布立国 | 新罗四十七年 |
| 曦临 | 781年缔结曦光盟约 | 曦光二百二十年 |
| 月兰渡 | 604年缔结白石盟约 | 白石三百九十七年 |
| 云梦 | 963年完成纳土归一 | 归一三十八年 |
| 苍梧 | 180年确立苍梧枢制 | 第十四木轮第四十一年 |
| 云牧川 | 以当代大可汗即位纪年 | 当代大可汗在位十二年 |
| 青岚谷 | 内部纪年不公开 | 对外使用通历 |
| 天华 | 312年建国 | 已灭亡 |
| 临渊 | 建国时间尚未确定 | 已灭亡 |

## 第一纪：远古诸族时代

| 年代 | 事件 |
|---|---|
| 通历前约3500年以前 | 旧神、神界、冥界与凡间已经存在。建木苍梧生长于南方大地，被视为天地初分时遗留的世界锚点之一。 |
| 通历前约3200年 | 人族、龙族、凤凰族、精灵等主要凡族已经出现，主要以分散聚落、氏族和迁徙群体存在。 |
| 通历前约3000年 | 各主要凡族形成稳定聚落、语言、祭祀传统和早期政治组织。 |
| 通历前约2800年 | 不同凡族开始建立跨聚落联盟，出现早期城邦、部落联盟和祭祀中心。 |
| 通历前约2600年 | 凡间文明已经能够稳定举行与神界、冥界沟通的仪式。神使和冥界代行者开始介入凡族事务。 |
| 通历前约2400年 | 凡族中出现最早的升格者，即后来新神的前身。 |
| 通历前约2250年 | 龙族中出现第一批化神者。部分龙神以自身神性创造龙裔，龙裔由此被称为“神明之子”。 |
| 通历前约2150年 | 部分旧神为建立凡间代行群体而赐福人族，最早的长生种出现。 |
| 通历前约2050年 | 神使、新生神明、冥界代行者和凡族祭司开始直接参与凡间政治。 |
| 通历前约1950年 | 旧神、新生神明与冥界存在围绕凡间归属、灵魂去向和信仰来源发生冲突。 |
| 通历前约1880年 | 凡族诸国分别依附不同神性阵营，三界之间的局部战争不断扩大。 |

## 第二纪：三界大战与断界

| 年代 | 事件 |
|---|---|
| 通历前约1800年 | 三界大战全面爆发。凡族联军、旧神、新生神明、神使与冥界诸神共同参战。 |
| 通历前约1790年 | 神界与冥界直接向凡间投入力量，部分地区的空间和灵魂循环发生异常。 |
| 通历前约1780年 | 战争结束，三界被迫接受“断界秩序”，永久性大型通道开始关闭。 |
| 通历前约1750年 | 后世正式形成旧神、新神、冥神三种分类。 |
| 通历前约1720年 | 神界通道大多封闭，但旧神、新神和神使仍可通过有限方式进入凡间。 |
| 通历前约1700年 | 最后一批稳定冥界通道关闭。冥神改以祭司、仪式、梦境和请神影响人间。 |
| 通历前约1650年 | 幸存神明重新划分权能范围，大量失去神明回应的教团衰亡。 |
| 通历前约1600—1200年 | 凡间文明进入漫长重建期。 |
| 通历前约1100年 | 各地重新形成稳定国家和文字传统。 |
| 通历前约900年 | 建木苍梧周边形成较稳定的凤凰族、龙裔与人族共治传统。 |
| 通历前约600年 | 多地出现连续保存至今的历法、族谱、祭祀记录和城邦档案。 |
