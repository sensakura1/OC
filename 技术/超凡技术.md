# 超凡技术

## 第一章 超凡力量分类

凡间超凡力量分为四类：

| 类别 | 使用者 | 性质 |
|---|---|---|
| 附魔 | 普通人可以学习 | 强化已有物质和器具 |
| 符道 | 普通人可以学习、制作和使用 | 通过符箓、阵式和媒介储存、引导或触发效果 |
| 炼金术 | 普通人可以研究和操作 | 依靠设备、公式、能源和符阵改变物质 |
| 神性法术 | 神明、神使及神明应许之人 | 直接调用神明权柄或神性力量 |

普通人不能仅凭学习便以自身意志操纵火焰、雷电、生命、空间、心智和灵魂。

普通人可以使用预制的雷符、火符、飞行符等符箓。此时真正产生效果的是符箓的结构、储能和触发机制，而不是使用者本人获得了相应权能。

卫文弘等超越常规神性体系的存在属于异常个体，不代表普通法术教育体系。

## 第二章 附魔

附魔主要用于增强已有物质的结构和性能，包括：

- 提高硬度与韧性；
- 降低金属疲劳；
- 增强耐热、耐寒与耐腐蚀性能；
- 稳定枪管与炮管；
- 提高刀剑刃口保持能力；
- 加固建筑、桥梁、车辆和掩体；
- 减少机械震动；
- 提高符箓载体的能量承受能力；
- 降低医疗植入物的排异和磨损。

附魔只能强化已有物质，不能无中生有。材料越差，强化上限越低。大型建筑必须分区附魔，多种相冲突的附魔可能造成材料失效。

附魔会因磨损、辐射、核爆、电磁冲击和符文破坏而衰退。

## 第三章 符道

符道通过符文、图形、方位、材料和触发条件建立超凡效果。

符箓的力量可以来自：

- 制作时注入的热能、电能或机械能；
- 炼金材料内部储存的能量；
- 使用时发生的化学反应；
- 环境中的火焰、雷电、水流和地热；
- 神明、神使或神许者预先注入的神性力量；
- 大型符阵和国家储能设施。

### 常见符箓

| 类型 | 用途 |
|---|---|
| 加固符 | 稳定器具、建筑、道路和防御工事 |
| 警戒符 | 感应触碰、破坏、生命活动和异常能量 |
| 封闭符 | 封锁门窗、容器、档案和仓库 |
| 认证符 | 验证军令、身份、密码本和重要器物 |
| 储能符 | 储存电能、热能和其他可用能量 |
| 隔绝符 | 削弱声音、电磁、热量、辐射和超凡能量传播 |
| 稳定符 | 稳定炼金反应、核设施和精密设备 |
| 医疗符 | 监测生命体征和维持器官保存环境 |
| 照明符 | 提供公共、矿井和应急照明 |
| 雷符 | 释放电能，攻击人员或破坏设备 |
| 火符 | 产生高温、火焰或点燃可燃物 |
| 爆裂符 | 释放压力和动能 |
| 震符 | 制造局部冲击和震荡 |
| 烟符 | 释放烟幕或刺激性气体 |
| 缚符 | 展开网具或短时拘束结构 |
| 破甲符 | 将能量集中于较小区域 |
| 乱讯符 | 制造局部电磁和符道干扰 |

攻击符可以投掷、粘附、埋设，或装入箭矢、枪弹和炮弹。

普通人可以触发雷符和火符，但不能脱离符箓持续操纵雷火。

## 第四章 飞行符具

飞行符、浮空符和减重符能够使普通人获得短时间飞行能力。

军事飞行者通常使用由多张符箓、附魔装备、储能器和控制翼面组成的完整飞行符具。

飞行符具具有以下限制：

- 能量和符箓寿命有限；
- 载重较低；
- 高速飞行难以控制；
- 强风、暴雨和高空低温会增加风险；
- 符箓损坏可能造成坠落；
- 雷符、乱讯符和反符武器可以破坏控制结构；
- 使用者必须经过专门训练。

## 第五章 神性法术

直接操纵元素、生命、空间、心智、灵魂和大范围自然现象，通常属于神性法术。

只有神明、神使和得到神明明确应许的人可以使用。

得到神明应许的人称为神许者。神许者仍是凡人，不等于神使。

神许者具有以下限制：

- 权能范围由神明决定；
- 不能自行学习其他权能；
- 力量可能被神明收回；
- 使用权能消耗体力、精神或神恩；
- 不自动获得神使的不死性；
- 不自动获得F=100；
- 不自动获得教团统治地位。

神使能够使用所奉神明更完整的权能并获得神性加护，但仍可能被击退、封印、拘束、俘获或以弑神武器伤害。

神明能够决定局部战局，却不能独自完成长期占领、行政、运输和治安。
