# 超凡技术

## 第一章 超凡力量分类

世界观中的凡间超凡力量按来源分为世间术法、神恩、冥仪和种族天赋。

本文件按照实现与调用方式，整理其中已经形成稳定技术体系或明确授权体系的四类力量：

| 类别 | 使用者 | 性质 |
|---|---|---|
| 附魔 | 普通人可以学习 | 属于世间术法，强化已有物质和器具 |
| 符道 | 普通人可以学习、制作和使用 | 属于世间术法，通过符箓、阵式和媒介储存、引导或触发效果 |
| 炼金术 | 普通人可以研究和操作 | 属于世间术法，依靠设备、公式、能源和符阵调整物质结构 |
| 神性法术 | 神明、神使及获得持续或临时授权之人 | 通过神恩或其他明确神性授权调用神明权柄或神性力量 |

普通人不能仅凭学习便以自身意志操纵火焰、雷电、生命、空间、心智和灵魂。

龙裔、凤凰族等种族的部分能力虽然源自创造其种族的神祇，但已经固化为种族自身的神源性种族天赋。此类天赋受个体身体、生命积累和种族生理结构限制，不等同于使用者持有相应神性权柄。

## 第二章 附魔

附魔主要用于增强已有物质的结构和性能，包括提高硬度与韧性、降低金属疲劳、增强耐热耐寒与耐腐蚀性能、稳定枪管炮管、加固建筑车辆、减少机械震动和提高符道载体承受能力。

附魔只能强化已有物质，不能无中生有。材料越差，强化上限越低。附魔会因磨损、高温、剧烈冲击、能量过载、电磁干扰和符文破坏而衰退。

### 武器附魔与适配调律

火铳、栓动步枪和早期火炮可以依靠普通机械与化学工业正常制造和使用，不必逐件接受复杂附魔。自动枪械和现代性能火炮若要在连续振动、高温、膛压和高速运动中保持强度、精度与可靠性，则通常需要对枪管或炮管、枪机或炮闩、供弹结构、附魔层和所用弹药进行整体适配调律。

工业可以批量制造标准零件，但最终调律必须根据每件成品的材料批次、加工误差、振动特征和磨损状态完成，不能把一件武器的参数直接复制到全部同型产品。更换关键零件、长期射击、过热、撞击或改用不同批次弹药，都可能造成调律偏移，表现为精度下降、供弹故障、附魔衰退或结构损伤。

弹药附魔必须同时兼顾弹壳、底火、发射药、弹头与武器调律。直接附魔火药容易形成异常能量集中和局部热点，存在自燃或爆炸风险；附魔弹头和弹壳虽然较安全，也仍需重新验证膛压、燃速、密封和附魔兼容性。因此，附魔枪弹属于高成本专项产品，不能作为长期大规模战争的普遍消耗品。

冷兵器没有火药、底火和连续供弹结构，弓箭的箭杆与箭头也可以分开制作和附魔。它们的载体面积较大、附魔结构较简单，损坏前还能反复使用，因此在长期战争中具有更高的附魔投入回报。

## 第三章 符道

符道通过符文、图形、方位、材料和触发条件建立超凡效果。符箓的力量来自制作时注入的能量、炼金材料内部储能、化学反应、环境能量、神性注入或大型储能设施。

### 常见符具

| 类型 | 用途 |
|---|---|
| 加固符 | 稳定器具、建筑、道路和防御工事 |
| 警戒符 | 感应触碰、破坏、生命活动和异常能量 |
| 封闭符 | 封锁门窗、容器、档案和仓库 |
| 认证符 | 验证军令、身份、密码本和重要器物 |
| 储能符 | 储存电能、热能和其他可用能量 |
| 隔绝符 | 削弱声音、电磁、热量和超凡能量传播 |
| 稳定符 | 稳定炼金反应、魔能核心和精密设备 |
| 调律符 | 校正动力核心、导能回路和复杂符阵的工作状态 |
| 紧急封闭符 | 在核心或回路受损时切断能量传播 |
| 生命体征监测符 | 读取并传递脉搏、呼吸、体温和血压等信息 |
| 病情记录符 | 记录生命体征、用药、输血和手术过程 |
| 器械稳定符 | 降低精密器械的震动、偏移和失准 |
| 容器封闭符 | 封闭药品、血液、无菌器械和样本容器 |
| 环境警戒符 | 监测隔离边界和无菌区域是否遭到破坏 |
| 照明符 | 提供公共、矿井和应急照明 |
| 雷符 | 释放电能，攻击人员或破坏设备 |
| 火符 | 产生高温、火焰或点燃可燃物 |
| 爆裂符 | 释放压力和动能 |
| 烟符 | 释放烟幕或刺激性气体 |
| 缚符 | 展开网具或短时拘束结构 |
| 破甲符 | 将能量集中于较小区域 |
| 乱讯符 | 制造局部电磁和符道干扰 |

符道能够感知、记录、传递、封闭、警戒和稳定器械，但不直接改变生命体的伤势、生理状态或生命力。

由外部术式主动作用于生命体，并直接产生止血、愈合、组织修复、器官恢复或生命补充效果的可授权超凡力量，归入神性生命权柄。普通医学、自然愈合以及已经固化为种族生理能力的神源性种族天赋不在此列。

## 第四章 飞行符具

飞行符、浮空符和减重符能够使普通人获得短时间飞行能力。军事飞行符具由多张符箓、附魔装备、储能器和控制翼面组成。

其限制包括能量和符箓寿命有限、载重较低、高速难以控制、天气影响明显、符箓损坏可能坠落，以及需要专门训练。

## 第五章 神性法术

直接操纵元素、生命、空间、心智、灵魂和大范围自然现象，通常属于神性法术。

只有神明、神使和得到神明明确授权的人可以使用神性法术。授权可以长期有效，也可以只在一次仪式、一次行动或有限次数内有效；效果类型、范围、强度和持续时间均受授权内容限制。

神明作出回应不代表必然授予力量。回应可以是允许、附条件允许、缩减授权、延后授权或明确拒绝。普通祭司只有在当次获得授权时才能临时引导相应神力，不能把一次授权永久转化为自身能力。

神使能够使用所奉神明更完整的权柄并获得神性加护，但仍可能被击退、封印、拘束、俘获或以弑神武器伤害。

神明能够决定局部战局，却不能独自完成长期占领、行政、运输和治安。
