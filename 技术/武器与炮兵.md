# 武器与炮兵

## 第一章 武器总体格局

通历1000年的军队以冷兵器及混合装备步兵为数量主体，以火器、炮兵、符道武器、飞行力量和魔能战争机械构成高价值火力。

“冷兵器仍是主力”是指冷兵器部队承担最多的战线维持、复杂地形作战、阵地突入、守备、巡逻和占领任务，不代表冷兵器能够在开阔地正面抵抗准备充分的火器和炮兵阵地。

## 第二章 冷兵器体系

军队常用冷兵器包括长矛、枪戟、盾牌、刀剑、战斧、弓弩、附魔武器和符道辅助装备。

长兵器和盾牌用于维持阵线、保护射手、阻挡冲击和控制狭窄通道。刀剑、战斧和短柄武器主要用于壕沟、街巷、建筑、森林、舰船、地下设施和阵地内部的近距离战斗。

弓弩制造和维护较容易，弹药可以地方生产，也能够携带比普通枪弹更完整的烟幕、缚束、警戒或破符结构，但射程和精度不能与高质量步枪竞争。

## 第三章 火器层级

### 火铳与早期枪械

火铳、前装枪和早期后装枪广泛存在于地方军、城防军、民兵、商队护卫和国力有限的正规军中。

### 栓动步枪

栓动步枪主要装备强国中央军、边防军、专业射手和火力分队。设计原理并不秘密，但稳定生产需要枪管钢、枪机加工、底火、弹壳、标准弹药和测量工具。

### 自动步枪

自动步枪只由明确的精锐突击部队、最高级特殊部队和直属护卫正式列装，不属于普通中央军、普通守军或常规防线。

自动步枪不是实验孤品。具备相应工业条件的国家可以生产和仿制，但其弹药消耗、枪管磨损、备件需求、供弹机构和训练成本阻止了普遍列装。

精锐分队以短点射和严格射击纪律提供局部、短暂的连续火力，不承担覆盖整条战线的持续射击任务。

### 高精度狙击枪

高精度狙击枪只由精锐专业射手和最高级特殊部队列装。其制造依赖高质量枪管、稳定弹药、精密瞄具、环境测量和严格校准。

狙击手主要攻击军官、炮兵观察员、符师、通信人员、神许者、魔能机械操作人员和其他高价值目标。

### 连续射击武器

各国已经掌握利用枪械结构连续射击的基本技术，但尚未建立普遍的机枪生产、供弹和列装体系。

少量重型连续射击武器只存在于国家试验场、首都要塞和极少数战略设施。它们通常体积大、重量高、耗弹惊人，并且需要固定枪架、冷却结构、专门供弹和军械人员。

这类武器不是普通军队的制式装备，也没有形成独立机枪兵种。

## 第四章 火器没有全面取代冷兵器的原因

一支火器部队持续作战需要火药、底火、弹壳、弹头、统一口径、替换枪管、军械师、弹药仓库、道路运输和长期射击训练。

冷兵器和弓弩同样需要材料、维护和训练，但可以更多依赖地方铁匠、木匠、皮匠和普通仓储体系。

各国因此把优质火器集中配发给中央军、边防军、射手和精锐部队，以冷兵器及混合装备部队承担数量更大的战线、守备和占领任务。

## 第五章 火力与防护边界

普通甲胄和盾牌不能可靠抵挡步枪弹。附魔甲胄可以降低破片、火铳弹、远距离弹丸和非正中命中的伤害，但不能使穿戴者免疫步枪和炮弹。

大型阵列盾、加固符和阵地符障可以在短时间内削弱集中射击，为部队跨越街道、壕沟间隙或局部开阔地提供掩护。这类防护需要预先充能，承受连续命中后会衰减，也可能被炮弹、破符弹和集中火力击穿。

在准备充分的防御阵地上，火铳、少量栓动步枪、弓弩、后装轻炮、野战炮和符道武器能够形成分层远程火力。

这种火力无法像普遍列装的连续射击武器一样持续封锁整片战场，却足以重创在开阔地保持密集队形、缺少掩护与火力支援的冷兵器部队。

自动步枪不属于普通防御阵地的标准组成。只有精锐部队被调往关键节点时，自动步枪才会在短时间内形成局部连续火力。

## 第六章 符道武器

军队可以使用雷符、火符、爆裂符、烟符、缚符、破甲符、破符弹和乱讯符。

攻击符可以投掷、粘附、埋设，或装入箭矢、枪弹和炮弹，用于制造烟幕、破坏火力点、干扰通信、攻击魔能回路、加固掩体和破坏附魔装甲。

## 第七章 炮兵定位

炮兵负责破坏阵形、摧毁工事和符阵节点、压制步枪阵地与弓弩、制造烟幕和突破通路、攻击指挥通信和补给节点，以及掩护步兵和魔能战争机械接近。

炮兵能够决定双方以何种状态进入近战，但不能代替地面部队搜索、突入、占领和守备。

## 第八章 火炮类型

| 类型 | 通常射程 | 主要用途 |
|---|---:|---|
| 营属轻炮 | 1—3公里 | 直接支援、霰弹射击和压制盾阵 |
| 迫击炮 | 1—4公里 | 曲射攻击壕沟、建筑和遮蔽目标 |
| 山地炮 | 2—6公里 | 山地、雨林、荒漠和恶劣道路地区 |
| 野战炮 | 4—10公里 | 阵地压制、直射与反击 |
| 榴弹炮 | 6—15公里 | 炮火准备、工事破坏和纵深打击 |
| 重型榴弹炮 | 10—20公里 | 反炮兵、要塞节点和国家级目标 |
| 岸防炮 | 视地形而定 | 封锁港口和攻击舰船 |
| 舰炮 | 视舰船而定 | 海战、岸轰和港口防御 |
| 高射炮 | 视口径而定 | 攻击龙族、龙骑、凤凰族和符具飞行单位 |

不存在成熟的火箭炮兵体系。重炮数量少，运输、部署、炮管寿命和炮弹供应都限制其使用。

## 第九章 炮兵弹药

| 弹药 | 用途 |
|---|---|
| 实心弹、穿甲弹 | 攻击城门、舰船、车辆和魔能机械 |
| 高爆弹 | 摧毁工事、建筑和密集目标 |
| 破片弹 | 杀伤暴露人员和低空目标 |
| 霰弹 | 近距离阻挡冲锋 |
| 烟幕弹 | 遮蔽步兵和战争机械推进 |
| 燃烧弹 | 点燃营地、仓库和木制工事 |
| 照明弹 | 夜间照明和辅助防空 |
| 符弹 | 携带雷符、火符、震符和乱讯符 |
| 破符弹 | 破坏符阵、附魔工事和魔能回路 |

## 第十章 炮兵观察与通信

炮兵依靠前沿观察员、光学测距、地图测绘、高地观察、凤凰族、龙骑、飞行符兵和感知类神许者修正射击。

有线通信是最可靠的指挥方式。无线电主要配发给军团、炮兵群、要塞和重要机动部队，只有少量精锐观察分队拥有便携式电台。

## 第十一章 防空

防空预警依靠观察哨、听音装置、警戒符、探照灯、龙骑和凤凰族巡逻。

普通地面部队可以使用火铳、栓动步枪和弓弩进行集中对空射击，但射程、精度和射击机会有限。真正有效的防空主要依靠后装轻炮、高射炮、定时破片弹、雷符弹、缚束符具，以及龙骑和凤凰族截击。

驻守关键设施的精锐部队可以使用自动步枪对低空目标短时间集中射击，但这不是普通军队的常规防空方式。

## 第十二章 火力使用限制

持续数日的大规模密集炮击极为少见。炮弹与枪弹产量、火药和底火、炮管寿命、役畜、道路、仓储、观察通信和国家财政都限制持续射击。

火力通常集中用于短时间准备、压制关键节点和掩护突破，而不是持续覆盖整个战场。
