# 武器与炮兵

## 第一章 武器总体格局

通历1000年的战争以冷兵器集团作战为主体，火器、符箓、炮兵和神性力量作为辅助。

火铳和栓动步枪是火器内部的主要类型，不表示步枪兵是军队主体。

军队中数量最多的仍是：

- 长矛、枪戟和盾牌兵；
- 刀剑、斧锤等近战兵；
- 弓弩手；
- 使用附魔武器和甲胄的精锐；
- 携带攻击符和辅助符的符兵。

## 第二章 火器

当代火药性能接近现实世界现代无烟发射药，但枪械和弹药产量有限。

火铳包括滑膛、线膛、前装、后装单发、火帽击发、底火击发和符道击发等类型，大量装备地方军、民兵和普通部队。

栓动步枪主要装备中央军、边防军、精锐射手和国力较强的军队。

全自动轻武器没有大量普及。自动步枪仅由少量特殊部队、直属护卫和重要设施守军使用。

重机枪与固定机枪主要用于要塞、军港、核设施、防空阵地和国家主力军。

冷兵器仍用于弹药耗尽、巷战、山地、雨林、船舱、夜袭、破阵和占领阵地。

## 第三章 符道武器

军队可以使用雷符、火符、爆裂符、烟符、缚符、破甲符和乱讯符。

攻击符可以投掷、埋设，或者装入箭矢、枪弹和炮弹。

符道武器是有限次数的预制军械，不代表普通士兵能够自行施展元素法术。

## 第四章 炮兵定位

炮兵负责：

- 破坏敌军阵形；
- 摧毁工事和符阵节点；
- 压制火铳、步枪和弓弩阵地；
- 制造烟幕和突破通路；
- 打击通信站、指挥所和弹药库；
- 掩护冷兵器部队接近；
- 阻断援军和撤退；
- 攻击空中目标。

炮兵能够决定双方以何种状态进入近战，但不能独自完成阵地占领。

## 第五章 火炮类型

| 类型 | 通常射程 | 主要用途 |
|---|---:|---|
| 营属轻炮 | 2—6公里 | 直接支援、发射霰弹和压制盾阵 |
| 山地炮 | 3—10公里 | 山地、雨林、荒漠和道路恶劣地区 |
| 迫击炮 | 1—6公里 | 曲射攻击战壕和隐蔽目标 |
| 野战榴弹炮 | 6—15公里 | 炮火准备、阵地压制和支援推进 |
| 重型榴弹炮 | 10—20公里 | 反炮兵、纵深打击、发射核炮弹 |
| 重炮 | 12—30公里 | 国家级远程火力和战略目标攻击 |
| 岸防炮 | 15—30公里 | 封锁港口和攻击舰船 |
| 舰炮 | 视舰船而定 | 海战、岸轰和港口防御 |
| 高射炮 | 视口径而定 | 攻击生物和符具飞行目标 |

不存在火箭炮和专门的重型攻城炮。

重炮不是专门攻城的兵器，而是用于远程压制、反炮兵和攻击重要设施的国家级武器。

## 第六章 炮兵弹药

| 弹药 | 效果 |
|---|---|
| 实心弹、穿甲弹 | 攻击城门、舰船、车辆和大型目标 |
| 高爆弹 | 摧毁工事、建筑和密集部队 |
| 破片弹 | 杀伤暴露人员和飞行目标 |
| 霰弹 | 近距离攻击冲锋部队 |
| 烟幕弹 | 掩护冷兵器部队推进 |
| 燃烧弹 | 点燃营地、仓库和木制工事 |
| 照明弹 | 夜间照明和辅助防空 |
| 符弹 | 携带雷符、火符、震符和乱讯符 |
| 破符弹 | 破坏符阵和附魔工事 |
| 核炮弹 | 由具有核投射资格的重型榴弹炮发射 |

## 第七章 炮兵观测

由于雷达尚未发明，炮兵依靠：

- 前沿观察员；
- 光学测距；
- 地图和测绘；
- 龙骑和凤凰族观察员；
- 飞行符兵；
- 神许飞行者；
- 少量飞机；
- 感知类神许者。

观察员通过有线通信、无线电报和便携式电台报告弹着点。

## 第八章 炮兵运用

炮兵常用直接射击、间接射击、预定射击、拦阻射击、炮火准备、徐进弹幕和反炮兵射击。

持续数日的密集炮击极为少见。炮弹、火药、运输能力和炮管寿命无法支持长期无限消耗。

炮火准备通常持续数轮或数十分钟，随后由冷兵器部队进入阵地。

## 第九章 防空

空中战力以龙族、龙骑、凤凰族、飞行符兵和神许飞行者为主，机械飞机数量很少。

防空依靠：

- 观察哨；
- 听音装置；
- 警戒符；
- 军事探照灯；
- 高射机枪和高射炮；
- 无线电预警网；
- 龙骑、凤凰族和飞行符兵拦截；
- 烟幕、伪装和防空网具。

雷符弹特别适合攻击飞行符具和通信设备。
