# 战争尺度

## 第一章 战争基本形态

通历1000年的战争以冷兵器集团作战为主体。

火器、炮兵、符箓、核炮弹、龙骑和神性力量负责改变接敌条件，冷兵器部队负责突破阵形、夺取阵地和控制土地。

炮火和枪弹决定双方以何种状态进入近战，冷兵器交锋决定战线是否真正崩溃。

## 第二章 火器没有取代冷兵器的原因

### 产量与弹药

现代枪药性能先进，但高质量枪管、枪机、底火和弹壳产量有限。

矛、盾、刀剑和弓弩更容易生产、维修和补充。

### 射速

火铳装填缓慢。火铳兵完成数轮射击后，往往退入冷兵器阵列后方，或者使用刺刀和刀剑参战。

栓动步枪射速较高，但数量和弹药储备不足以独自维持整条战线。

### 附魔防护

附魔盾牌、甲胄、加固符和阵地符可以降低普通火铳的杀伤效果。

这些防护不能使士兵免疫步枪弹，却能帮助阵列承受远程攻击并接近敌军。

### 符箓掩护

烟符、加固符、雷符和飞行符具可以遮蔽射界、破坏火器阵地并帮助近战部队接敌。

### 占领要求

火器和炮兵不能独自检查建筑、控制街道、夺取符阵节点和押送俘虏。

最终仍需地面部队进入目标区域。

## 第三章 常见会战流程

1. 龙骑、斥候和飞行符兵侦察敌军；
2. 炮兵、火铳、弓弩和攻击符进行远程试探；
3. 栓动步枪手射击军官、符师、通信兵和神许者；
4. 双方以烟符、雷符、火符和炮火破坏阵形；
5. 必要时使用小型核炮弹突破关键节点或打击通信；
6. 盾兵与长兵器方阵推进；
7. 火铳兵退入阵后装填或加入近战；
8. 冷兵器集团进行正面决战；
9. 精锐、神许者、龙骑或神使攻击关键节点；
10. 一方崩溃后由骑兵和飞行单位追击。

## 第四章 兵种定位

| 兵种 | 定位 |
|---|---|
| 长矛、枪戟兵 | 正面战线主体，抵御冲锋和维持阵形 |
| 盾兵 | 掩护推进，抵挡箭矢、火铳和攻击符 |
| 刀剑、斧锤兵 | 近战、破甲和清理阵地 |
| 弓弩手 | 持续射击，可发射符箭 |
| 火铳兵 | 阵前齐射和近距离高威力攻击 |
| 栓动步枪手 | 精确射击和压制关键目标 |
| 自动步枪手 | 极少数精锐的短时压制火力 |
| 符兵 | 使用雷符、火符、烟符和加固符 |
| 炮兵 | 破坏阵形、工事和通信 |
| 骑兵、龙骑 | 机动、侧击、追击和纵深突袭 |
| 飞行符兵 | 侦察、传令、投符和低空突击 |
| 神许者、神使 | 反制敌方超凡力量和攻击关键节点 |

## 第五章 军队规模

| 层级 | 常见人数 |
|---|---:|
| 特种小队 | 5—20人 |
| 连队冲突 | 50—300人 |
| 营团战斗 | 300—3000人 |
| 正规会战 | 3000—30000人 |
| 大型战役 | 30000—100000人 |
| 全国战争 | 十万以上，分布于多个战区 |

炮兵、核炮弹、飞行力量和神性法术使军队不能过度密集。

十万以上兵力通常分布于多个战场，而不是排列在同一片战场上。

## 第六章 强国步兵班组

国力强大的国家，一个步兵班可能包括：

- 班长一人；
- 副班长一人；
- 长兵器与盾兵若干；
- 火铳兵或栓动步枪手若干；
- 自动步枪手零至一人；
- 通信兵一人，携带便携式电台；
- 符兵一人，携带雷符、火符、烟符或警戒符；
- 医疗兵一人。

实际编制根据国家、地区和部队等级变化。

## 第七章 战略资源

战争中的关键资源包括：

- 粮食和饮水；
- 火药、底火和弹药；
- 枪管钢、炮钢和附魔材料；
- 军用符箓；
- 炼金催化剂；
- 电池和无线电；
- 药品、血液和医疗耗材；
- 核炮弹和裂变材料；
- 神许者、神使和专业技术人员；
- 车辆、牲畜、道路和水运。

一支拥有先进武器的军队仍可能因弹药、粮食和通信中断而战败。

## 第八章 超凡战力

普通符师和附魔师属于技术人员，不是能够徒手施放元素法术的战斗法师。

普通神许者可以改变小范围战斗，但仍会被火铳、步枪、炮弹和攻击符杀死。

神使能够突破普通阵地，却不能无限承受持续重炮、核炮弹、封印和神性克制。

神明可以决定局部战局，但不能代替军队完成占领、运输、治安和行政。
