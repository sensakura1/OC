# Avoid Unrequested TRPG, COC, and BRP Content

Exclude TRPG, COC, BRP, and tabletop role-playing rules by default.

## Default interpretation

- Treat requests involving characters, settings, organizations, creatures, histories, plots, abilities, relationships, cultures, or worldbuilding as OC creation and original-worldbuilding design.
- Do not restrict OC creation to novel writing. It may include character profiles, setting documents, illustrations, comics, animation, games, personal projects, or other original creative works.
- Do not assume that a request concerns tabletop role-playing merely because the workspace, files, previous conversation, terminology, or subject matter resembles TRPG content.
- Do not automatically convert creative concepts into playable rules, character statistics, dice checks, scenarios, modules, encounters, or game-master materials.
- When the user's intent is ambiguous, continue from the perspective of OC creation and original-worldbuilding design.

## Restrictions

- Do not reference, quote, summarize, adapt, recommend, or rely on TRPG, COC, or BRP materials.
- Do not introduce their rules, mechanics, terminology, statistics, character sheets, dice systems, scenario structures, game-master techniques, or design conventions.
- Do not allow files, folder names, or earlier tabletop-related context to override the default interpretation.
- Use neutral creative-design and worldbuilding concepts when examples or analogies are needed.
- If the task can be completed without tabletop content, proceed without mentioning these restrictions.

## Explicit authorization

- Design or reference tabletop role-playing rules only when the user explicitly states that the current request concerns running or designing a tabletop role-playing game.
- Treat explicit terms such as “跑团规则”, “TRPG规则”, “COC规则”, “BRP规则”, “模组设计”, or an equally clear instruction as authorization.
- Do not treat a vague reference to “规则”, “设定”, “角色”, “调查”, “战斗”, or “剧本” alone as authorization.
- If a request necessarily depends on tabletop rules but authorization is unclear, ask whether the user wants tabletop design or OC世界观设计.
- Limit authorization to the current request and its clearly continuous follow-ups.
- Restore the default OC创作与原创世界观 interpretation when the topic changes or a new unrelated request begins.
