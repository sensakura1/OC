# 外交格局

> **编写备注：本文件所列各国外交关系均为暂稿，用于建立当前国际结构的初步框架，后续仍需结合各国历史、地理、经济与具体事件继续修改。除已经在其他设定中明确确立的事实外，本文中的关系强度、结盟形式、争议内容与外交走向均不视为最终定稿。**

本文件记录当代各国的外交准则、结盟形式、当前关系、主要争端及危机处理方式。

世界地理、主权原则和基本外交惯例以《国际秩序》为准。本文件以国家为单位整理外交设定，不重复论述完整地貌与经济网络。

## 第一章 国家关系与外交规则

### 第一节 总体关系与结盟

国家之间的总体关系、结盟领域和对具体争端的立场，不属于同一套分类。

判断两个国家之间的关系时，应分别记录：

1. 双方总体关系如何；
2. 双方是否结盟；
3. 结盟涉及哪些领域；
4. 盟约具有多强的约束力；
5. 是否承担共同参战义务；
6. 是否存在融合等特殊政治方向；
7. 双方在具体战争或争端中采取何种立场。

两个关系友好的国家不一定结盟；两个互不信任的国家也可能因共同利益建立经济联盟。

#### 总体关系

| 关系 | 含义 |
|------|------|
| 特殊合作 | 在多个重要领域保持长期而稳定的协调，关系明显高于普通友好国家 |
| 友好 | 保持稳定外交、通商、人员往来和有限互助 |
| 务实往来 | 因交通、贸易、边境或安全需要合作，但缺乏深层政治认同 |
| 冷淡 | 保留正式交往，但往来规模有限，缺少主动合作意愿 |
| 敌对 | 存在领土、政权正当性、宗教或国家安全冲突 |
| 战争状态 | 法律上仍处于战争之中，即使没有持续发生军事行动 |

总体关系用于描述两国在较长时期内的基本相处状态，不直接决定双方承担何种盟约义务。

特殊合作并不必然通向国家融合。两个国家可以长期保持密切合作，同时永久维持各自主权和制度。

融合属于少数国家之间的特殊政治方向，不列入普遍关系等级。

只有双方明确承认制度接轨、共同机构、一体化发展或最终合并属于长期目标时，才能认定双方具有融合意愿。

#### 结盟形式

结盟不只指军事同盟。国家可以在单一领域结盟，也可以同时在多个领域建立共同制度。

| 结盟形式 | 主要内容 | 是否必然共同参战 |
|----------|----------|------------------|
| 一体化共同体 | 建立常设共同机构，在市场、人员流动、法律、外交或安全等领域逐步统一，并让渡部分原由各国独立行使的权力 | 否，取决于共同体条约 |
| 综合联盟 | 在政治、经济、安全、交通等多个领域长期协调，但保留完整国家主权 | 否 |
| 共同防御同盟 | 约定成员遭受外国进攻时，其他成员承担军事援助义务 | 通常是 |
| 有限军事同盟 | 只针对特定敌国、地区、战争或威胁进行军事合作 | 仅限约定范围 |
| 军事合作协定 | 涉及联合训练、情报交换、军需供应、道路使用或临时共同指挥，但不承担自动参战义务 | 否 |
| 经济联盟 | 在关税、市场、货币结算、商路、投资、物资供应或人员流动等一个或多个领域实行共同政策 | 否 |
| 安全与情报联盟 | 共同追查间谍、叛乱组织、海盗、跨境犯罪或特定神性威胁 | 否 |
| 外交协调联盟 | 在对外承认、制裁、谈判及重大国际问题上采取共同立场 | 否 |
| 专项联盟 | 围绕粮食、水利、医药、航运、界门、灾害或疫病等单一事务建立共同机制 | 否 |

一体化共同体并不等于建立统一国家。

共同体成员仍可保留各自的统治者、军队、地方行政、国籍、法律及独立处理的内政领域。

共同体与普通综合联盟的区别，在于共同体拥有常设机构，并且成员已经将部分权力交由共同机制行使。

天霜与曜穹现阶段属于特殊合作关系，具有明确融合意愿，并在政治、军事、情报和制度接轨等多个领域进行综合协作，但尚未建立一体化共同体，也不存在自动参战义务。

### 第二节 经济结盟

经济联盟内部存在多种形式。

| 形式 | 内容 |
|------|------|
| 优惠贸易协定 | 成员之间降低部分商品的关税和贸易限制 |
| 关税联盟 | 成员内部减少关税，并对外采用共同或协调后的关税政策 |
| 共同市场 | 允许货物、资本、商人及部分人员在成员之间较自由地流动 |
| 货币与结算联盟 | 统一货币、银两标准、汇兑制度或跨境结算规则 |
| 交通联盟 | 统一道路、港口、船籍、驿站、通行文书及运输标准 |
| 物资保障联盟 | 对粮食、战马、药材、金属或其他战略物资承担优先供应义务 |
| 多领域经济联盟 | 同时覆盖关税、市场、交通、结算和物资供应中的多个领域 |

经济联盟不必以政治认同为前提。

两个关系冷淡的国家，也可能为了维持河道、商路、粮食或水源而参加同一个经济联盟。

经济结盟不等于军事结盟。成员在战争中可以保持中立，也可以按照预先约定对交战成员实施贸易限制。

### 第三节 盟约约束强度

同一种结盟形式，可以具有不同的约束强度。

| 强度 | 含义 |
|------|------|
| 定期协商 | 成员只承担会谈、通报和讨论义务 |
| 协调行动 | 成员承诺尽量采取一致政策，但保留最终决定权 |
| 优先互助 | 特定情况发生时，成员必须优先向盟友提供援助 |
| 强制义务 | 条约条件满足后，成员必须履行军事、经济或其他责任 |
| 共同机构 | 由常设机构负责执行共同政策 |
| 权力让渡 | 成员将部分原本属于本国的决定权交给共同机构 |

判断一个联盟的实际作用时，不能只看名称，还要看成员承担的是协商义务、优先互助义务、强制义务，还是已经建立共同机构。

### 第四节 中立立场

中立不是固定的双边关系等级，而是一个国家对特定战争、联盟或争端采取的立场。

| 类型 | 含义 |
|------|------|
| 长期中立 | 国家长期拒绝加入排他性军事集团，不主动参与外国战争 |
| 战争中立 | 只在某一场战争中不帮助任何交战方 |
| 武装中立 | 不参加战争，但以军事力量保护本国边境、航路和贸易 |
| 商业中立 | 不提供军事援助，但在法律允许范围内继续与交战双方贸易 |
| 事务中立 | 只在特定政治、宗教或继承争端中不支持任何一方 |

中立国仍可与交战国保持友好关系、参加经济联盟或履行灾害与人道事务协定。

同一个国家也可能在一场战争中保持中立，却在另一场战争中履行共同防御义务。

### 第五节 外交交涉与争端处理

保持正常外交关系的国家，可以在对方都城设置常驻使节或使馆。

常驻使节负责：

- 传递国书；
- 解释本国政策；
- 协助本国商人和居民；
- 处理人员被捕和财产纠纷；
- 通报灾害及重大事件；
- 安排正式访问；
- 参与条约谈判。

使馆不被视作使节所属国家的领土。所在国仍然拥有主权，只是在外交惯例上不会随意进入、搜查或扣押使馆文书。

没有常驻关系或处于敌对状态的国家，通常使用临时使团。

临时使团可以处理停战、战俘交换、遗体归还、赎金、边境赔偿、疫病通报、重大水灾、神性灾害及统治者死亡通知等事项。

第三国没有预先确定的调停职责，也不会仅因没有参加某场战争便自动成为中立调停者。

一国能否参与斡旋，取决于：

1. 是否得到争端双方同意；
2. 是否与双方都保留有效交涉渠道；
3. 是否直接参与争端或从结果中获得重大利益；
4. 是否具备传递信息、召集会谈或监督协议的能力；
5. 是否愿意承担调停失败造成的外交后果。

第三国在交涉中可能承担不同角色：

| 角色 | 含义 |
|------|------|
| 传话者 | 只负责传递双方不愿直接交换的信息 |
| 会谈场所提供者 | 允许双方使团在本国会面，但不参与谈判内容 |
| 斡旋者 | 分别与双方交涉，尝试缩小立场差距 |
| 调停者 | 主动提出停战、赔偿或边境处理方案 |
| 见证者 | 见证协议签署并保存副本 |
| 保证者 | 承诺在一方违约时采取制裁、断交或其他措施 |
| 专业参与者 | 只处理水利、医药、航运、商事或灾害等专业问题 |

同一个国家可以在一场争端中担任斡旋者，在另一场争端中成为直接当事国。

国家也可以只提供会谈场所，而拒绝承担中立、监督或保证责任。

调停行为不代表该国在其他问题上保持中立，也不代表争端双方接受其长期政治立场。

涉及海盗、走私、绑架医者及其他非国家组织的案件，通常属于跨境执法或安全合作，不属于国家间调停。只有在相关组织受到外国政府庇护、资助或指挥时，案件才可能上升为正式外交争端。

### 第六节 主权与跨境活动

诸国不承认外国军队、官员和神职人员拥有未经许可的跨境执法权。

人员越过边境后，应由所在国决定是否拘留、遣返、审判、提供居留或转交第三国。

普通犯罪者、政治叛逃者、战俘和难民应当分别处理。

神明和神使的外交身份取决于其实际政治职位，而不是单纯取决于神性。

天霜圣女、曜穹圣女以国家最高统治者身份出访时，按照国家元首对待。

没有国家职位的神明进入外国时，不自动获得国家元首身份。

神使若没有正式使节身份，只是具有特殊力量的外国人员，不能以神明命令为由要求司法豁免。

外国神明传递的神谕，不会自动在当地取得法律效力。

未经许可在外国领土举行大规模请神、开启大型界门或让武装神性力量跨境，通常被视为严重的主权侵犯。

### 第七节 各国关系总览

| 国家 | 总体外交定位 | 主要合作关系 | 主要国家间矛盾 | 特殊关系或立场 |
|------|--------------|--------------|----------------|----------------|
| 天霜 | 东北强国、天华继承国之一 | 与曜穹全面协作；与云梦、曦临保持正常往来 | 与新罗的政权正当性及战争问题；与云牧川的牧道、河源和临渊旧地边界问题 | 与曜穹具有融合意愿；对新罗保持战争状态 |
| 曜穹 | 中央强国、天华正统继承者 | 与天霜全面协作；与云梦、曦临、月兰渡保持稳定往来 | 与新罗的正统性及战争问题；与月兰渡的关税问题；与云牧川的边界和王庭责任问题 | 与天霜具有融合意愿；对新罗保持战争状态 |
| 曦临 | 东南沿海商贸国家 | 与云梦保持河海合作；与曜穹、月兰渡及多数开放国家通商 | 与新罗的逃民、走私、越境追捕和船籍问题；与云梦的转运税和商团影响问题；与苍梧的港口和商业权限问题 | 倾向商业中立，不承担未经商人议会批准的外国战争义务 |
| 新罗 | 封闭国家、政治孤立者 | 无公开盟国；与云梦保持最低交涉 | 与天霜、曜穹处于战争状态；与曦临存在边境、逃民和海上冲突；与云梦存在短边界安全问题 | 通过封锁国境和有限秘密贸易维持政权 |
| 月兰渡 | 西部绿洲与陆路枢纽 | 与曜穹维持东西商路；与云牧川开展互市；与曦临保持货物流通 | 与曜穹存在重复征税和附属关隘问题；与云牧川存在水源、冬季牧场和商队保护费争议 | 重视白石盟约、绿洲自主和商路连续性 |
| 云牧川 | 北方游牧联盟 | 与月兰渡开展互市；与天霜、曜穹保持边贸 | 与天霜存在牧道、河源和临渊旧地边界问题；与曜穹存在固定国界和部族责任问题；与月兰渡存在水源和保护费争议 | 王庭条约未必能立即约束所有部族 |
| 青岚谷 | 封闭的医药国家 | 与各国保持有限医药往来；与云梦、苍梧、曦临的实际交通较多 | 暂无固定敌对国家；与苍梧、云梦围绕通行边界、医者保护和药材流动存在有限协调问题 | 不参加军事联盟，不允许外国驻军，不因行医支持任何国家立场 |
| 苍梧 | 西南中央集权国家 | 与云梦保持水系和物资合作；与曦临保持沿海贸易；与月兰渡保持支路往来 | 与云梦存在上游水利、边市和资源出口问题；与曦临存在港口及商团影响问题；与曜穹存在外国神权活动边界问题 | 承认外国主权，但严格限制外国势力进入核心地区 |
| 云梦 | 东部内河与粮食国家 | 与曦临保持河海合作；与曜穹、苍梧保持稳定往来；与天霜正常交往 | 与曦临存在转运税、商团和水利问题；与曜穹存在粮道及政治影响问题；与新罗存在难民和短边界安全问题 | 坚持守土中立，不允许外国军队借道进攻第三国 |

本表中的“主要国家间矛盾”不等于敌对关系。

同一对国家可以同时存在重要合作和利益冲突。例如月兰渡与云牧川既依赖互市，也围绕水源和牧场发生争议；云梦与曦临既共同维持河海运输，也竞争粮食定价和转运收益。

海盗、走私集团、盗采者、绑架者及叛乱组织不列为外交对象。相关问题应在具体国家章节中作为跨境安全问题处理；只有外国政府直接包庇、资助或指挥这些组织时，才转化为国家间矛盾。

## 第二章 天霜

### 第一节 外交准则

天霜外交以维护国家主权、安全与法律秩序为根本。

主要原则包括：

1. 自主决定内政与外交，不接受任何国家以历史、文化、宗教或其他理由干涉天霜国家事务；
2. 以维护国家安全和领土完整为对外行动边界，不以扩张和支配其他国家为目标；
3. 坚持属地管辖与法律面前身份平等，任何外国个人与机构均不得因国籍、职务、政治地位、宗教身份或神性取得法外特权；
4. 对涉及共同机构、制度接轨或政治整合的对外关系，坚持地位平等、相互自愿、条件成熟和审慎渐进，不接受单方面归附或仓促合并。

### 第二节 当前外交处境

天霜拥有基本自给的农业、畜牧、渔业和国家储粮体系，不依赖外国粮食维持国家生存。

对外贸易主要用于获得温地特产、稀有药材、特殊工艺及本国不易生产的物资。

天霜控制原天华东北故地和原临渊主要领土，因此同时面对曜穹方向的长期合作、云牧川方向的牧道和边境问题、东北海岸的海运安全、临渊旧地的治理及对新罗战争状态所产生的政治责任。

### 第三节 与曜穹

天霜与曜穹属于具有融合意愿的特殊合作关系。

双方在情报、军事协调、档案整理、灾害通报、道路标准和人员交流方面逐步接轨。

天霜不将曜穹视为潜在敌国，也不反对未来建立共同体或统一国家。

现阶段不立即合并，主要是因为两国制度、军队、财政和地方行政尚未完成衔接。

### 第四节 与新罗

天霜不承认新罗统治集团的政权正当性，与新罗保持战争状态。

双方没有常驻外交，只通过第三国和临时使团处理战俘、遗体、灾害及其他必要事务。

天霜对新罗的敌对主要针对其统治集团、逆臣传统和现实安全威胁，不等于将所有新罗普通民众视为同等敌人。

### 第五节 与云牧川

天霜与云牧川属于边境紧张下的务实往来。

主要争议包括季节牧民越境、河源和冬营归属、牲畜扣押、商队劫掠、临渊旧地边界解释及王庭协议能否约束边境部族。

严重冲突发生后，天霜与云牧川可以直接谈判，也可以在双方共同接受的情况下邀请第三国传话、见证或斡旋。

第三国是否参与以及承担何种职责，必须由天霜、云牧王庭及实际涉及争端的部族另行确认，不存在预先确定的调停者。

### 第六节 与其他国家

天霜与云梦保持正常外交和物资往来。

天霜与曦临通过东北海运进行贸易，但不会允许曦临商团干预本国港口治理。

天霜与月兰渡、苍梧、青岚谷之间没有主要政治冲突，往来规模受距离限制。

---

## 第三章 曜穹

### 第一节 外交准则

曜穹外交以维护国家正统、政治独立与稳定的区域秩序为根本。

主要原则包括：

1. 坚持曜穹作为天华中央政治与皇室正统主要继承者的国家定位；
2. 尊重国家主权，不将历史传承、文化影响或宗教权威自动解释为对外国领土及事务的支配权；
3. 以维护稳定、连续且能够容纳正常国家交往的区域秩序为长期目标；
4. 对涉及共同机构、制度接轨或政治整合的对外关系，坚持地位平等、相互自愿和共同协商，不要求任何一方单方面归附另一方。

### 第二节 当前外交处境

曜穹位于大陆中央偏东地区，同时连接西部月兰渡商路、北方云牧川、东北天霜、东部新罗、东南云梦及经云梦与曦临相接的海上网络。

中央位置为曜穹带来贸易与政治影响，也迫使其同时处理多个方向的外交问题。

### 第三节 与天霜

曜穹与天霜具有共同历史、共同敌人和明确融合意愿。

曜穹不要求天霜放弃现有制度并单方面并入曜穹。

双方当前优先推进法律文书互认、道路和通行标准统一、官员与神职人员交流、军事情报共享、对新罗政策协调及联合机构的可行性研究。

### 第四节 与新罗

曜穹认为新罗统治集团源自天华逆臣势力，不承认其正统性。

双方在主要边界保持高度军事戒备。

曜穹尚未重启全面战争，原因包括占领成本、战后治理困难、东部交通风险及与天霜协调尚未完成。

### 第五节 与云梦

曜穹与云梦总体友好。

双方合作涉及粮食、道路、学术、文书、灾害和货物转运。

曜穹承认云梦不属于天华旧有皇权体系，不以文化影响作为主权依据。

云梦拒绝曜穹利用粮道和商路干预其内政。

### 第六节 与曦临及月兰渡

曜穹与曦临保持大规模通商，需要其海上出口和船运网络。

双方主要争议是宗教法律、外国商人待遇、港口禁运和曦临商团的政治影响。

曜穹与月兰渡依靠东西商路形成稳定务实关系，主要矛盾集中在关税、关隘和商队管理。

### 第七节 与云牧川

曜穹需要云牧川的战马和草原物产，也必须处理牧道和边境责任问题。

曜穹倾向于要求王庭统一承担边境责任，但云牧川内部的部族自治使这一要求难以完全落实。

## 第四章 曦临

### 第一节 外交准则

曦临外交以维护共和国自主、航行自由、契约秩序与开放交往为根本。

主要原则包括：

1. 维护海上通行与跨国交往的开放性，反对任何国家垄断主要海路并以此支配其他国家；
2. 坚持契约、信用和法律责任不因短期政治变化而被任意否定；
3. 外交、条约与战争义务必须依照共和国法定程序决定，不接受任何国内外力量越权代替国家作出承诺；
4. 对外合作以自愿、互利和责任明确为基础，不以商业依赖换取政治支配。

### 第二节 当前外交处境

曦临位于新罗南部及大陆东南、南部海岸，拥有多个港口、沿海城邦和近海岛屿。

其影响力来自船队、港口、仓储、商票、航路情报和跨国商团，而非对大陆内地的直接统治。

曦临总体采取商业中立和武装自保相结合的外交方式，但这种中立只适用于其明确选择不参加的战争，不代表曦临在所有国家争端中没有自身立场。

### 第三节 与云梦

曦临与云梦总体友好，并建立河海交通、水利、灾害及跨境经济合作。

双方相互依赖：云梦需要曦临的海上出口，曦临需要云梦的粮食和内河货物。

主要争议包括转运税、仓储费、粮价、水利工程及曦临商团在云梦的经济影响。

### 第四节 与新罗

曦临与新罗直接接壤。

两国长期围绕逃民、走私、船籍、渔区、越境追捕和禁运货物发生冲突。

曦临不寻求主动吞并新罗，也不愿协助新罗维持全面封锁。

双方关系冷淡且高度戒备，但没有公开战争状态。

### 第五节 与曜穹和天霜

曦临与曜穹总体友好，在海运和中央市场方面互相依赖。

曦临与天霜维持东北海运和正常贸易。

曦临不会因天霜、曜穹对新罗保持战争状态，便自动参加对新罗的军事行动。

### 第六节 与西南及西部国家

曦临与苍梧保持受控沿海贸易，但不得以债务或护航为由控制苍梧港口。

曦临与月兰渡通过东西货物流通形成长期商业联系。

曦临尊重青岚谷医药中立，也反对任何国家独占其医术。

## 第五章 新罗

### 第一节 外交准则

新罗外交以维持政权存续、国家独立与统治秩序为根本。

主要原则包括：

1. 拒绝接受外国对新罗政权合法性的裁定，不允许外部势力以正统争议干涉其国内统治；
2. 一切外交关系与对外承诺均须服从于政权延续和内部稳定，不得削弱中央统治权；
3. 不接受以天华正统、文化归属或历史继承为基础的外部政治领导；
4. 避免使国家受到单一外国或外国集团的支配，不承担足以危及政权存续的外部义务。

### 第二节 当前外交处境

新罗没有公开盟国。

它与天霜、曜穹保持战争状态，与曦临长期戒备，与云梦保留最低限度交涉。

闭关锁国并没有使新罗在地理上与世隔绝。漫长海岸、南部边界和多个港湾，使其无法彻底消灭走私和人员外逃。

### 第三节 与天霜、曜穹

新罗将两国描述为试图吞并东部沿海的外部强权。

三方没有常驻使馆，只通过临时使团和经各方同意的传话者处理必要事务。

新罗高度警惕天霜与曜穹逐步融合，因为两国一旦统一军事、财政和外交政策，新罗面临的外部压力将显著增加。

### 第四节 与曦临

新罗视曦临为最主要的人员外逃和秘密贸易通道。

新罗指责曦临纵容走私和叛逃者；曦临则指责新罗越境追捕和扣押商船。

双方都不希望局部冲突扩大为长期全面战争。

### 第五节 与云梦

新罗与云梦只有一小段共同边界。

双方关系冷淡，主要进行灾害通报、受控交换、难民审查和边境交涉。

新罗不希望云梦成为天霜、曜穹进攻新罗的通道；云梦也明确拒绝外国军队借道。

### 第六节 与其他国家

新罗与月兰渡、云牧川、青岚谷和苍梧缺少大规模直接外交。

来自这些地区的物资主要经过曦临、云梦或其他第三方进入新罗。

## 第六章 月兰渡

### 第一节 外交准则

月兰渡外交以维护白石盟约、绿洲共同体统一与国家自主为根本。

主要原则包括：

1. 白石盟约是国家对外行动的最高制度基础，任何外交承诺均不得损害盟约秩序；
2. 维护绿洲城、沙民部族、商会与圣殿共同组成的政治共同体，不允许外国势力支配、分裂或取代这一共同体；
3. 对外交往坚持主权平等、相互守约和责任对等；
4. 不因宗教联系、商业依赖或外部安全压力放弃国家的自主判断。

### 第二节 当前外交处境

月兰渡是大陆西部最重要的绿洲国家和陆路枢纽。

其影响力来自水源、驿站、道路和商队服务，而非大规模领土扩张。

月兰渡需要同时处理曜穹、云牧川、曦临和西南支路上的利益。

### 第三节 与曜穹

月兰渡与曜穹通过东西商路紧密联系。

双方合作包括道路维护、商队调查、关税文书、灾害通报和使团通行。

主要争议是重复征税、附属政权加收费用及战时禁运。

### 第四节 与云牧川

月兰渡与云牧川属于务实往来。

双方需要彼此的粮食、盐、金属、牲畜、战马和道路信息，也经常围绕冬季牧场、水源和商队保护费发生冲突。

王庭签订的条约未必能立即约束所有边境部族。

### 第五节 与曦临及西南国家

月兰渡与曦临分别控制陆路和海路的重要部分，双方在货物流通上互相补充。

月兰渡可以通过东南支路与苍梧、卢家堡等地区往来。

月兰渡通常不介入天霜、曜穹与新罗之间的正统争端，但可以根据自身利益决定是否参与相关通商限制或外交交涉。

## 第七章 云牧川

### 第一节 外交准则

云牧川外交以维护草原联盟自主、诸部共同利益与王庭统一为根本。

主要原则包括：

1. 对外交往应同时维护王庭代表联盟整体的权威与诸部在联盟内的既有地位；
2. 不接受外国以定居国家的制度和疆域观念否定草原诸部的传统生存方式与正当权利；
3. 对外承诺应符合联盟的实际组织能力，不以无法约束诸部的名义承诺换取短期利益；
4. 不允许外国势力利用部族差异分裂草原联盟，或使王庭及个别部族沦为外国附庸。

### 第二节 当前外交处境

云牧川不是高度统一的官僚国家。

外国与王庭签订协议后，仍可能需要分别得到左右翼、叶护或边境部族的承认。

这种结构使云牧川具有强大的军事动员潜力，也使其外交承诺容易受到部族政治影响。

### 第三节 与天霜

云牧川与天霜围绕临渊旧地、牧道、河源、冬营和边境追击存在长期争议。

双方同时保留互市和物资交换，因此关系属于边境紧张下的务实往来。

### 第四节 与曜穹

云牧川向曜穹提供战马、牲畜和草原物产，从曜穹获得金属、织物及农耕商品。

双方主要分歧是曜穹要求王庭统一负责边境事件，而王庭未必能够完全控制所有部族。

### 第五节 与月兰渡

月兰渡是云牧川获取粮食、盐、金属和西部商品的重要渠道。

双方既合作又围绕商税、水源和部族劫掠发生冲突。

### 第六节 对外战争立场

云牧川是否参加外国战争，取决于王庭决策、战利分配和诸部支持。

即使大可汗宣布参战，部分部族也可能只承担有限义务；反之，边境部族也可能在王庭没有宣战时自行发动冲突。

## 第八章 青岚谷

### 第一节 外交准则

青岚谷外交以维护国家独立、中立地位、医者使命与内部知识自主为根本。

主要原则包括：

1. 不参加外国之间的权力集团和争霸，不以国家立场支持任何一方的领土、继承或正统主张；
2. 医疗救助独立于政治和战争立场，不因救治对象的身份改变其中立性质；
3. 对外交往不得危及青岚谷的内部自治、医术传承与知识自主；
4. 对外医疗合作必须以尊重医者的专业判断、人身安全和行动自由为前提。

### 第二节 当前外交处境

青岚谷疆域较小，却因稀有药材、疑难病症治疗和毒理知识保持特殊地位。

各国尊重其独立，不是因为存在共同强制法律，而是因为没有国家愿意让竞争者独占青岚医术。

青岚谷的中立是其自身外交选择，不代表其承担调停其他国家争端的责任。

### 第三节 与各国的关系

青岚谷与其他国家均可保持有限医药往来，但不建立排他性政治联盟。

它与云梦、苍梧及曦临的实际往来相对较多，因为这些国家控制其主要陆路、河路和海上转运方向。

青岚谷暂无固定敌对国家。其国家间问题主要涉及与邻近国家协调通行边界、医者保护、药材流动和外国人员入境。

### 第四节 医者保护

外国势力伤害、绑架或强留青岚医者时，青岚谷可以召回本国医者、中止药材供应、拒绝相关国家人员入谷、公布违约行为或要求有关国家进行交涉。

青岚谷不会主动发动对外战争，但会使用医药断绝、外交拒绝和情报封锁维护自身安全。

---

## 第九章 苍梧

### 第一节 外交准则

苍梧外交以维护国家主权、建木国本与制度自主为根本。

主要原则包括：

1. 坚持国家主权平等与相互不干涉，不以苍梧制度支配外国，也不接受外国干预苍梧内政；
2. 建木国本、木律及三族共治秩序属于苍梧专属国家事务，不接受外部权威裁定；
3. 外国政治、宗教及其他组织不得在苍梧境内形成脱离国家法律与管辖的独立权力；
4. 对外交往不得以削弱建木国本、国家统一或制度自主为代价。

### 第二节 当前外交处境

苍梧是西南最大的中央集权国家。

其山地、雨林和河谷使外国大军难以进入，也限制苍梧自身向外进行大规模军事投送。

苍梧需要云梦和曦临提供运输，同时防止两国的商业影响转化为政治控制。

### 第三节 与云梦

苍梧与云梦总体友好，在木材、矿物、药材、河道和转运领域保持合作。

主要争议包括上游水利、河流泥沙、边市权利、资源出口数量及人员移交。

### 第四节 与曦临

曦临承担苍梧部分沿海运输。

苍梧不允许曦临商团通过债务、仓储和护航控制本国港口。

曦临要求苍梧明确关税、船只扣押和货物检查标准。

### 第五节 与青岚谷

苍梧承认青岚谷独立。

强行控制青岚谷的军事与后勤成本过高，也会破坏苍梧自身所需的医药往来，并引起其他国家反对。

双方可能在药材、边境通行和外来人员问题上发生争议，但没有根本敌对关系。

### 第六节 与神权国家

苍梧限制外国神权组织，并不等于必然敌视所有信奉神明的国家。

曜穹、天霜或月兰渡的正式使者可以进入许可区域，但不得以传教或神谕为由干预苍梧秩序。

苍梧与曜穹之间的主要外交问题，是如何划定正常使节活动、私人信仰与有组织神权扩张之间的边界。

---

## 第十章 云梦

### 第一节 外交准则

云梦外交以维护国家主权、守土中立与国内安定为根本。

主要原则包括：

1. 坚持防御性的国家立场，不主动改变现有国界，不协助任何国家侵略第三国；
2. 不接受外国对云梦领土、国家决策及公共秩序形成支配；
3. 不因文化、贸易、学术或长期合作关系接受外国政治领导；
4. 对外争端优先采取协商与有限合作，不参与同本国主权和安全无直接关系的国家争霸。

### 第二节 当前外交处境

云梦西北部与曜穹接壤，北部中段与新罗短暂接壤，东北部与曦临接壤。

这种边界结构使云梦同时连接中央陆路、东部封闭边境和南方海运。

云梦的外交重点不是扩大领土，而是防止自身水网和粮仓成为外国战争目标。

### 第三节 与曦临

云梦与曦临总体友好，并在河海交通、水利、灾害及经济领域建立专项合作。

双方相互依赖，也围绕转运税、仓储费、粮价、商票和水利工程发生争议。

云梦不允许曦临商团控制本国粮食政策；曦临也不接受云梦政府直接指挥其港口和船队。

### 第四节 与曜穹

云梦与曜穹总体友好，双方保持粮食、道路、学术和文书往来。

云梦承认曜穹的国家地位，但不属于天华旧有皇权体系，也不接受曜穹提出主权要求。

曜穹需要云梦粮道，云梦需要曜穹提供进入大陆中央和西部市场的通道。

### 第五节 与新罗

云梦与新罗只有一段较短边界。

双方关系冷淡，主要处理边境警戒、难民、受控交换、疫病和灾害通报。

云梦不会允许天霜或曜穹借道进攻新罗，也不会允许新罗军队进入云梦追捕逃亡者。

### 第六节 与天霜和苍梧

云梦与天霜保持正常外交和物资往来。

云梦与苍梧总体友好，在水系、木材、药材、矿物和转运方面保持合作。

云梦不参加天霜、曜穹对新罗的战争，但可以根据自身利益和各方请求决定是否参与灾害、停战和人员交换交涉。

### 第七节 对外交涉与有限斡旋

云梦与曜穹、新罗、曦临分别接壤，并与天霜、苍梧保持往来，因此拥有较多区域交涉渠道。

这种地理位置不意味着云梦天然中立，也不意味着云梦有责任调停东部所有争端。

云梦是否参与斡旋，取决于：

- 争端是否影响云梦河道、粮运、边境或难民安全；
- 争端双方是否共同接受云梦参与；
- 云梦是否会因调停结果承担过高风险；
- 参与交涉是否符合三院合议作出的国家决定。

云梦可以提供传话、会谈场所、灾情核验及协议见证，也可以完全拒绝介入与本国利益无关的争端。

云梦不会为调停结果自动提供军事担保，也不会允许外国以会谈、护送或监督协议为由在本国长期驻军。
